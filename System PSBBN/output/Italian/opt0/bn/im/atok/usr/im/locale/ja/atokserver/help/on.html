Enable ATOK to use

Before using ATOK, you need to enable ATOK.

When the ATOK palette is displayed, it indicates that you can input Japanese using ATOK. If it is not displayed, press the half-width/full-width key or Ctrl + Space key to display the ATOK palette and be able to input Japanese.
Each time you press the half-width/full-width key or Ctrl + Space key, the ATOK palette will be shown/hidden.
