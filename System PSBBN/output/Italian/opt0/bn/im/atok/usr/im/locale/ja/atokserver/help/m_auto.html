Automatically convert and confirm                           

Set to automatically convert and confirm entered characters.
Conversion and confirmation operations can be kept to a minimum.

Automatically convert from the beginning

When automatic Kana-Kanji conversion is set, the characters you enter are automatically converted, so you don't have to be conscious of the conversion operation.
When punctuation marks and symbols are entered, they are converted and confirmed in order from the beginning.
If you want to use automatic kana-kanji conversion, set the kanji conversion mode on the input/conversion 1 sheet of the ATOK environment settings to automatic.

[example] If you enter "I will go shopping on Sunday."

  1. Enter "Nichiyobiwa".

  2. Enter ",".

  3. Enter "I'm going out to sea."

  4. Enter "."

  5. Press Enter or Ctrl+M (also) to confirm.

Convert punctuation marks at the same time as input

Configure settings for the function that executes conversion when punctuation marks, question marks, etc. are entered.
Normal conversion is performed using the space key, Shift + space key, or conversion (next candidate) key, but most punctuation marks and commas are entered at the break between phrases.
Therefore, by automatically converting at that timing, you can minimize the number of times you press the conversion (next candidate) key.

  1. Click [Preferences] on the ATOK palette.

  2. Select the input/conversion 1 sheet.

  3. Turn on Punctuation conversion and click Settings.
    The Punctuation Conversion Settings dialog box will appear.

  4. Set each item on/off.

  5. Click OK.
    Return to input/conversion 1 sheet.

  6. Click OK again.
    The character string you are inputting will be converted when the item you turned on in step 4 is entered.

Automatically confirm characters entered using fixed input

This is useful when you have a large amount of input that does not require conversion.
To actually input fixed characters, click on the ATOK palette and enter from fixed full-width katakana to fixed half-width alphanumeric. You need to select a character type.

  1. Click [Preferences] on the ATOK palette.

  2. Select the input/conversion 2 sheet.

  3. Select Yes in Fixed input confirmation priority.

  4. Click OK.

Automatic replacement of long sounds (-) and hyphens (-)

If the character before the long sound (-) is an alphabet, number, or symbol, replace the long sound (-) with a hyphen (-).
You can easily enter hyphens on keyboards that do not have a numeric keypad, such as on laptops.
Similarly, you can replace a comma (,) with a comma (,), a full stop (.) with a period (.), and a bullet (・) with a slash (/).

  1. Click [Preferences] on the ATOK palette.

  2. Select the input/conversion 1 sheet.

  3. Turn on Input Assistance and click Settings.
    The input support settings dialog box will be displayed.

  4. Turn on Auto-replace long sounds and punctuation marks.

  5. Click OK.
    Return to input/conversion 1 sheet.

  6. Click OK again.
