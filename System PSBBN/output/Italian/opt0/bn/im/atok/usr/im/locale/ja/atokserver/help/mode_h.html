Kanji conversion mode                           

Set the method to convert the input string to a mixture of Kanji and Kana.
To set the mode to always use, click [Menu] on the ATOK palette and select Kanji from the menu that appears. Select Conversion Mode to change the Kanji conversion mode.

Renbun-bushi kana-kanji conversion
Used for normal input/conversion. It is useful for converting long sentences containing compound words, number words, foreign words, suffixes, punctuation marks, etc.

Compound word Kana-Kanji conversion
Used to convert compound words that are followed by kanji, such as addresses, names, company names, department names, etc.
If there are conversion candidates for a full name and a place name with the same reading, you can also set which one to give priority to conversion.
Settings for proper noun priority, name priority, and place name priority are made in the ATOK environment settings, Input/Conversion 1 sheet, Compound word conversion details.

Automatic Kana-Kanji conversion
Automatically determines clause breaks and conversion candidates for the input sentence and performs conversion.
Conversion (Next Candidate) You can create sentences containing kanji and kana without having to worry about pressing keys.
