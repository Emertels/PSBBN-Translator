Register a word in the dictionary                           

By registering words that are not found in dictionaries, such as people's names and technical terms, you can create a dictionary that suits the user.
Registered words can be converted using the space key, Shift + space key, or conversion (next candidate) key.

Register a word using the word registration dialog box

Use the word registration dialog box to register words

  1. Click [Word Registration] on the ATOK palette.

  2. Set the word you want to register, its pronunciation, part of speech, etc.
    You can register words up to 64 characters, regardless of full-width or half-width.

  3. Click OK.
    The set word will be registered in the dictionary.
