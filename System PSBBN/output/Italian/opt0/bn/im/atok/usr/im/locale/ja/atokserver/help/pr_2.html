Input/conversion 2                           

Configure auxiliary settings related to input/conversion, such as whether to display messages for operation errors, details of the display format of candidate windows and word comments, etc.

■Explanation of setting items

  1. Numeric keypad half-width input
    Select Yes if you want to always enter half-width numbers using the numeric keypad. You can enter half-width numbers without doing any post-conversion or changing the character input mode.

  2. Romaji recovery
    When entering text that contains a mixture of alphabets and Japanese, select whether or not to display the parts that can be displayed in Japanese in kana. You can enter sentences by effectively using automatically registered words.
    No
    Words that cannot be converted to kana will be displayed in alphabetical order. All parts that can be written as
    and
    will be displayed in Japanese.
    Automatic
    Refers to the English words learned in the dictionary and displays other words in Japanese.

  3. Space key blank input
    Set whether the space entered with the space key follows the input character type or is full-width or half-width regardless of the input character type.

  4. Fixed input confirmation priority
    Set this when performing a large amount of input that does not require conversion. If you select Yes, you can omit the confirmation operation when making fixed inputs.

  5. Particle recovery priority
    You can perform the conversion immediately before the particle, and then set it to perform the correct conversion even if you input the phrase from the particle into small sections.

  6. Code system
    Select the code system when character input mode is set to code input mode or symbol input mode.

  7. Comment boundaries
    Select the comment display method to display the content of proofreading support and word comments.

  8. Error message
    Set whether to display an error message when you make a mistake in an operation.

  9. [Candidate window settings]
    Set the display of the candidate window, the selection method when inputting kana, and whether or not to display short-input candidates, half-width full-width candidates, and post-conversion candidates in the candidate window.

  10. [Return to initial value]
    Returns the settings of the input/conversion 2 sheet to the state immediately after installation.

[Candidate window settings]

■Explanation of setting items

  1. Number of conversions
    Sets the number of times the space key is pressed to display the candidate window during conversion. If you do not want to display the candidate window, enter 0.

  2. Select next candidate when inputting kana
    When inputting kana, select whether to use the "nu (1)" to "wa (0)" keys as kana keys for input, or to use them as numeric keys to select conversion candidates.
    Input
    Use as a kana key for input
    Select
    Used as a numeric key to select conversion candidates

  3. Display size
    Select the size of the candidate window.

  4. Add input-saving candidates
    Select whether to display input-saving candidates in the candidate window. Input-saving candidates are displayed at number 0, and selecting number 0 switches to the input-saving candidate window.

  5. Addition of both half-width and full-width candidates
    Select whether to always display full-width and half-width candidates in the candidate window.

  6. Adding post-conversion candidates
    Select whether or not to always display the same candidates in the candidate window when converting using the function keys (F6 to F10).
