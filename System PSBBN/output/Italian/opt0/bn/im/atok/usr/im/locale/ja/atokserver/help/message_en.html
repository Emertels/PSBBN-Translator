Message when registering words                           

This section explains the causes and solutions when a message appears.
Click on the line that corresponds to the first character of the message you are looking for.

A line ka line Sa line line ya line

A line

Lots of words with the same reading

  • Cause:
    The number of words for the reading you entered is full.
  • Workaround:
    Re-register with a different reading.

Top of this page                          

ka line

No more registrations possible with this reading.

  • Cause:
    The area around the set reading has become full.
  • Workaround:
    Re-register with a different reading.

No more registrations possible

  • Cause:
    The dictionary size has reached its limit.
  • Solution:
    Delete unnecessary words or examples and re-register.

Top of this page                          

Sa line

Word registration will be canceled because the dictionary is not set correctly

  • Cause:
    Dictionary file is not set.
  • Solution:
    Reset the dictionary file name correctly. The settings are made in Dictionary/Study Sheet in ATOK environment settings.

Top of this page                          

ta line

Word too long

  • Cause:
    Word exceeds 64 characters.
  • Solution:
    Re-enter within the character limit.

Word contains invalid characters

  • Cause:
    The word to be registered contains a code other than the character code.
  • How to deal with it:
    Kanji, hiragana, full-width and half-width katakana, alphabets, numbers, and symbols can be registered.

Registration failed

  • Cause:
    The dictionary file being set is not a dictionary that can be used with ATOK. Or the dictionary file is not set.
  • Solution:
    Reset the dictionary file name correctly. The settings are made in Dictionary/Study Sheet in ATOK environment settings.

Top of this page                          

ya line

Reading too long

  • Cause:
    The reading exceeds 32 characters.
  • Solution:
    Re-enter the correct pronunciation within the character limit.

Contains characters that are inappropriate for reading

  • Cause:
    Hiragana, full-width/half-width katakana, alphabets, numbers and symbols (# $ % & * + - / : ; < = > @ ¥ _ ' ^ ~ `) are used.
  • Workaround:
    Re-enter using available characters.

The first character of the reading is inappropriate

  • Cause:
    (-' ') is added at the beginning of the word reading.
  • Workaround:
    Re-enter using available characters.
