Environment settings message                           

This section explains the causes and solutions when a message appears.
Click on the line that corresponds to the first character of the message you are looking for.

Ka line

Basic dictionary set is invalid dictionary set

  • Cause:
    The dictionary is not set correctly.
  • Solution:
    Check whether the name of the dictionary set is set correctly, and whether the system dictionary, user dictionary, and auxiliary dictionary are set correctly.

Top of this page                          

Sa line

Dictionary set name not set

  • Cause:
    The name of the dictionary set is not set.
  • Workaround:
    Select a dictionary set for which no name has been set from the list of dictionary sets. Click [Rename dictionary set] and enter the name.

System dictionary cannot be treated as a dictionary

  • Cause:
    A dictionary other than ATOK is set in the system dictionary.
  • Workaround:
    Reset the correct dictionary file.

System dictionary not set

  • Cause:
    The system dictionary is not set.
  • How to deal with it:
    Set the system dictionary. Click [Browse] to browse the dictionary file on your hard disk.

System dictionary not found

  • Cause:
    The system dictionary does not exist with the specified file name.
  • How to deal with it:
    Re-enter the correct dictionary file name. Click [Browse] to browse the dictionary file on your hard disk.

The version of the system dictionary is different

  • Cause:
    A dictionary other than ATOK is set in the system dictionary.
  • How to deal with it:
    Reset the dictionary for ATOK.

User dictionary cannot be set in system dictionary

  • Cause:
    A user dictionary is being set as the system dictionary.
  • How to deal with it:
    Reset the system dictionary for ATOK.
