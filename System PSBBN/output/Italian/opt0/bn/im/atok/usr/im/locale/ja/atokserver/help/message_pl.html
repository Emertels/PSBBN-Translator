Messaggio delle impostazioni dell'ambiente                           

Questa sezione spiega le cause e le soluzioni quando viene visualizzato un messaggio.
Clicca sulla riga che corrisponde al primo carattere del messaggio che stai cercando.

La linea

Il set di dizionari di base non e valido

  • Causa:
    Il dizionario non e impostato correttamente.
  • Soluzione:
    Controllare se il nome del dizionario impostato e impostato correttamente e se il dizionario di sistema, il dizionario utente e il dizionario ausiliario sono impostati correttamente.

Sulla linea

Nome del dizionario impostato non impostato

  • Causa:
    Il nome del set di dizionari non e impostato.
  • Soluzione alternativa:
    Selezionare un set di dizionari per il quale non e stato impostato alcun nome dall'elenco dei set di dizionari. Fare clic su [Rinomina set dizionario] e inserire il nome.

Il dizionario di sistema non puo essere trattato come un dizionario

  • Causa:
    Nel dizionario di sistema e impostato un dizionario diverso da ATOK.
  • Soluzione alternativa:
    Reimpostare il file dizionario corretto.

Dizionario di sistema non impostato

  • Causa:
    Il dizionario di sistema non e impostato.
  • Come affrontarlo:
    Imposta il dizionario di sistema. Fare clic su [Sfoglia] per sfogliare il file del dizionario sul disco rigido.

Dizionario di sistema non trovato

  • Causa:
    Il dizionario di sistema non esiste con il nome file specificato.
  • Come affrontarlo:
    Reinserire il nome file del dizionario corretto. Fare clic su [Sfoglia] per sfogliare il file del dizionario sul disco rigido.

La versione del dizionario di sistema e diversa

  • Causa:
    Nel dizionario di sistema e impostato un dizionario diverso da ATOK.
  • Come affrontarlo:
    Reimposta il dizionario per ATOK.

Il dizionario utente non puo essere impostato nel dizionario di sistema

  • Causa:
    Un dizionario utente viene impostato come dizionario di sistema.
  • Come affrontarlo:
    Reimposta il dizionario di sistema per ATOK.
