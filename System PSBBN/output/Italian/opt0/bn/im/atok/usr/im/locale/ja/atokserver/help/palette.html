ATOK Palette                           

When you start ATOK by pressing the half-width/full-width key or Ctrl + Space key, the ATOK palette will be displayed.
The ATOK palette displays information necessary for inputting and converting characters, such as input mode.
You can also click the button to change the state.

1) Grip
Drag to move the ATOK palette.

2) Vertical/horizontal display switching
Switches the ATOK palette between vertical and horizontal each time you click.

3) Input character type
The characters that can be entered are displayed.
Click to change the input character type.

4) Kanji conversion mode
Displays how to convert the input characters into kanji and kana mixed sentences.
Click to change the Kanji conversion mode.

5) Character input mode
The input mode that can be used for input is displayed.
Click to change the character input mode to kanji input, half-width input, code input, or symbol input mode.

6) Menu
A menu will appear where you can change the input/conversion method or start the environment settings.

7) Click Palette
Starts a click palette that allows you to enter characters by moving the mouse cursor with a mouse or controller.

8) Environment settings
Start a tool to prepare the operating environment for comfortable input/conversion.

9) Word registration
Register the word in the dictionary.

10) Help
Display ATOK help.

11) Resize
Click the button in the top right corner to display all buttons in the ATOK palette or restore it to its original size.
You can change the number of displayed buttons by dragging the button at the bottom right.
