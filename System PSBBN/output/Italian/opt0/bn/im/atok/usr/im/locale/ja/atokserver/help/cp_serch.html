Radical list sheet

■Explanation of setting items

  1. Number of strokes
    Enter the number of strokes of the radical of the kanji you want to search.
    Click [Jump] to display a list of radicals with the corresponding number of strokes.

  2. [Jump]
    Jump to the set number of strokes.

  3. Radical list
    Radicals are displayed in order of stroke number.
    You can select radicals by clicking on the appropriate radical and clicking OK.

  4. Radical enlarged display
    Enlarges and displays the radical selected in the radical list.
    The position of radicals can be changed by dragging and dropping with the mouse.

  5. Position
    Select where the radical is located.
    Specifying the position of the radical makes it easier to narrow down the kanji.

Kanji reference sheet

■Explanation of setting items

  1. Kanji
    Enter the kanji to reference in order to extract radicals (parts).
    When you click [Search], the kanji will be displayed broken down into radicals (parts).

  2. [Search]
    Executes a search using the set conditions.

  3. Kanji reference list
    The kanji entered in the kanji field will be broken down into constituent radicals (parts) and displayed.
    You can select radicals by clicking on the appropriate radical and clicking OK.

  4. Radical enlarged display
    Enlarges and displays the radical selected in the radical list.
    The position of radicals can be changed by dragging and dropping with the mouse.

  5. Position
    Select where the radical is located.
    Specifying the position of the radical makes it easier to narrow down the kanji.
