Input/Conversion 1                           

Configure settings for how to input and convert characters, such as how to input and convert characters and how to add okurikana.

■Explanation of setting items
  1. Kanji input mode
    Select the method for entering characters from the keyboard when creating a kanji-kana mixture sentence.

  2. Input character type
    Select how the entered characters are displayed when in Kanji input mode.

  3. Kanji conversion mode
    Select the method to convert the entered characters into kanji and kana mixed sentences.
    Conjunction clause
    Used for normal input/conversion. It is useful for converting long sentences containing compound words, number words, foreign words, suffixes, punctuation marks, etc.
    Compound word
    Used to convert compound words followed by kanji, such as address, name, company name, department name, etc. If there are conversion candidates for a full name and a place name with the same reading, you can also set which one to give priority to conversion.
    Automatic
    Determines clause breaks and conversion candidates, and automatically converts and confirms input characters. You can create kanji-kana mixed sentences without having to worry about pressing the conversion (next candidate) key.

  4. Compound word conversion details
    You can select details about compound word preferences. Valid only when Kanji conversion mode is set to Compound word.

  5. Colloquialism preferred
    Select Yes if you want to convert spoken words preferentially. Words that cannot be converted normally (such as "I made it", "It's great", "Let's say it", etc.) can be converted.

  6. Fukukana mode
    Select how to send the okurigana.
    Main Rules
    This is the method of sending based on the Cabinet notification "How to assign okuri kana."
    Omit
    This is a method of sending by omitting the okigana that does not need to be written in the "main rules".
    Send
    Contrary to "omit", this is a method of sending without omitting.
    All
    Displays how to "omit" and "send" all at once.

    Main rulesEndRepresent
    OmitEndRepresent
    SendEndRepresent

  7. Punctuation mode
    Select which punctuation mark or parentheses (,,) (..) (/) ("" []) to input when you press the key.

  8. Input support/[Settings]
    Select whether to use the AI input support function that automatically corrects common input errors and the function that replaces long sounds (-) and hyphens (-) when inputting.
    You can also click Settings to configure details.

  9. Proofreading support/[Settings]
    Set whether to use the proofreading support function (JUST MEDDLER2) that points out omissions, misuse, and errors in kana.
    You can also click Settings to configure details.

  10. Half-width full-width conversion/[Settings]
    Set the function to convert the conversion result of katakana, alphanumeric characters, and symbols into half-width or full-width. By using this function, you can convert to half-width or full-width characters by simply pressing the space key without having to do any post-conversion or learning.
    You can also click Settings to configure details.

  11. Punctuation conversion/[Settings]
    Set whether to use the punctuation mark conversion function that performs conversion when punctuation marks are entered. This is valid when the kanji conversion mode is set to continuous clause or compound word conversion mode.
    You can also click Settings to configure details.

  12. Word comments
    When turned on, comments set for words will be displayed behind the conversion candidates. It also shows possible replacements for other words.

  13. [Return to initial value]
    Returns the settings of the input/conversion 1 sheet to the state immediately after installation.

Input support [Settings]

■Explanation of setting items

  1. Automatic input error repair
    ATOK automatically corrects input errors specific to Romaji input and Kana input and converts them into correct words.
    • Romaji input
      Excess/deficiency of vowels
      When vowels are consecutive, such as "(consonant + vowel) + vowel" or "(vowel) + (vowel)", incorrect conversion due to too many or insufficient vowels has been automatically corrected. I will correct it to
      [Example] NYURYOKU → Input (NYUURYOKU)
      Excess of consonants
      Automatically corrects excessive consonant input when inputting consonants consecutively to input the consonant 'tsu'.
      [Example] Kitte (KITTTE) → Stamp (KITTE)
      Excess or deficiency of "N"
      Automatically corrects incorrect conversions caused by inputting too much or not enough "N" to input "NN".
      [Example] SIZENNNNO → nature (SIZENNNO)

    • Kana input
      []']→['] If you enter
      ' (voiced mark) by mistake and enter ' (handakuten), it will be corrected automatically.
      [Example] Rakuka'ki → Graffiti
      "tsu" → "tsu"
      If you enter "tsu" by mistake instead of "tsu", it will be corrected automatically.

  2. Automatic replacement of long sounds and punctuation marks
    If the character before the long sound (-) is a letter, number, or symbol, replace the long sound (-) with a hyphen (-). You can easily enter hyphens on keyboards that do not have a numeric keypad, such as on laptops. Similarly, you can replace a comma (,) with a comma (,), a full stop (.) with a period (.), and a bullet (・) with a slash (/).
    [Example] Convert long sound to hyphen
    Input "Yuubin Bangou 770-0189"
    Conversion "Postal code 770-0189"

  1. Pointing out continuous particles
    Point out places where the case particles ``no'', ``de'', ``ga'', and ``wo'' are repeated excessively. Point out when "no" and "ga" are used three or more times in a row, and "de" and "wo" are used two or more times in a row.
    [Example]
    We'll meet at the park behind my house.
    I hurriedly took a taxi and went home.
    This is the book that I wrote with the pen that he gave me.
    Make a cake using strawberries.

Half-width full-width conversion [Settings]

■Explanation of setting items

  1. Katakana
    Select whether to always enter katakana in half-width or full-width. When you press the space key to convert, all katakana characters are converted to half-width or full-width characters.

  2. English characters
    Select whether to always enter alphabets in half-width or full-width. When you press the space key to convert, all alphabets will be converted to half-width or full-width characters.

  3. Numbers
    Select whether to always enter numbers in half-width or full-width. All numbers are converted to half-width or full-width characters when you press the space bar to convert.

  4. Symbols
    Choose whether to always enter certain symbols in half-width or full-width characters. When you press the space bar to convert, certain symbols are converted to half-width or full-width characters.

  5. [All half-width]
    Set all symbols to be entered in half-width characters.

  6. [All double-byte]
    Set all symbols to be entered in full-width characters.

  7. [All release]
    Set all symbols to No.

  8. Expansion of adaptation to characters being input
    Set whether to replace katakana, alphabets, numbers, and symbols with specified half-width or full-width characters, giving priority to the input character type from the characters being input before conversion. This setting is also applied to candidates for input saving and fixed repeat.

  9. Adaptation extension to user words
    Set whether to replace katakana, alphabets, numbers, and symbols in the converted string with the specified full-width or half-width characters for words registered by the user.

  10. Adaptive extension to post-transform operations
    Set whether to replace katakana, alphabetic characters, numbers, and symbols in the string with the specified half-width or full-width characters for post-converted characters.
    This is used to strongly suppress input of half-width katakana in Internet e-mails, etc.
