Enter katakana alphabet                           

Katakana and alphabets included in kanji-kana mixed sentences can be entered in the following four ways.
Select the operation method according to your preference and usage.

Convert input characters to katakana/alphabetic/Post conversion
Entering characters in katakana/alphabet/fixed input
Enable input characters to be displayed in katakana/alphabet/input character type
Set in half-width character input mode/Half-width input mode

Convert input characters to katakana/alphabetic/Post conversion

Converts the characters being input/converted into katakana or alphabet.
The converted characters are automatically registered in the dictionary using the dictionary learning function, so you can convert them using normal input and conversion operations next time.
If you are typing in kana, press the katakana hiragana key so that you can enter alphabets.

Character after conversionOperation
HiraganaF6 key or Ctrl+U (na) key
Full-width KatakanaF7 key or Ctrl+I (ni) key
Half-width KatakanaF8 key or Ctrl+O (ra) key
Full-width alphabetF9 key or Ctrl+P (Se) key
Half-width alphabetF10 key or Ctrl+@ key

[Example]
When converting "TOMATO"

  1. Enter "Tomato".

  2. Press F7 or Ctrl+I (to) to convert to katakana.

  3. Press F9 key or Ctrl+P (Se) key to convert to alphabet.

  4. Press F10 key or Ctrl + @ key to convert to half-width alphabet.

Entering characters in katakana/alphabet/fixed input

You can set the characters to be entered in advance so that they will not be converted to another character when you press the space key.
You can also change the input character type using the keyboard.

Characters to enterOperation
Half-width alphabetNo conversion key
Full-width/half-width alphabetShift + No conversion key
Full-width/half-width katakana and hiraganaCtrl + No conversion key
  1. Click on the ATOK palette.

  2. Select the character type to be input from full-width katakana fixed to half-width alphanumeric fixed.
    The display of will change.

  3. Enter characters.

Display input characters in katakana/alphabet/Input character type

Displays the entered characters on the screen in katakana or alphabet.
This is useful when you have many characters to type, as you do not need to press any keys to convert them.
Even when changing the input character type, you can use the space key to convert the text to a mixture of kanji and kana. However, if the input character type is half-width alphanumeric, use the conversion (next candidate) key or Shift + Space key to convert.

  1. Click on the ATOK palette.

  2. Choose from full-width katakana to half-width alphanumeric characters.
    The display of will change.

  3. Enter characters.

Set the mode to input half-width characters/Half-width input mode

When entering characters, numbers, and symbols on the keyboard in half-width characters, it is convenient to use half-width input mode. Characters entered in half-width input mode are not converted even if you press the space key.

  1. Press the F10 key or the convert (next candidate) key.
    Changes to half-width input mode.

  2. Enter characters.

  3. Press the F10 key three times or the convert (next candidate) key.
    Changes to the original input mode.
