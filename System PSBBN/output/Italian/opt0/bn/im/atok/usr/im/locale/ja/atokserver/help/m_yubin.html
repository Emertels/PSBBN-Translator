Use a postal code dictionary or single kanji dictionary                           

ATOK allows you to combine multiple dictionaries and use them for conversion.
Rather than registering many words in one dictionary, you can perform efficient conversion by using a combination of specialized terminology dictionaries.

Use a postal code dictionary

You can change from postal code to address.
There are three types of postal code dictionaries: atok12y7.dic, atok12yc.dic, and atok12y5.dic.
If "Dictionary file is not set" is displayed in step 2, set the postal code dictionary.
You can check which dictionaries are set in the dictionary set in Dictionary/Study sheet in ATOK environment settings.

Dictionary nameDescription
atok12y7.dicYou can convert from 7-digit postal code and 5-digit postal code to address.
atok12yc.dicYou can convert 7-digit postal code and 5-digit postal code to large business name.
atok12y5.dicYou can convert a 5-digit postal code to an address.

[Example]
If you enter "Kita-Aoyama, Minato-ku, Tokyo"

  1. Enter your postal code. You can enter in either full-width or half-width characters.

  2. Press F3 key to convert.

  3. Press Enter or Ctrl+M (also) to confirm.

Use a single kanji dictionary

The Single Kanji Dictionary (atok12tk.dic) contains kanji frequently used in names and addresses and their readings.
Kanji that cannot be converted using a regular dictionary can be easily converted using a single kanji dictionary.
If "Dictionary file is not set" is displayed in step 4, set a single kanji dictionary.

[Example]
When converting to Manae
  1. Enter "Manae".

  2. Press the space key, Shift+space key, or convert (next candidate) key to convert.

  3. Press Shift + → key to change the clause break to "mana".

  4. Press the F2 key to which the single kanji dictionary is assigned to convert.

  5. Press F2 again.
    A suggestion window will appear.

  6. Press the space bar to move the highlight cursor to "Love".

  7. Press Enter or Ctrl+M (also) to confirm.
