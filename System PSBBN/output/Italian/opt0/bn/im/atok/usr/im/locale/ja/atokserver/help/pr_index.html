ATOK environment settings                           

By changing the input/conversion method, you can create an operating environment that suits the user.
ATOK has many functions, so it can be used comfortably not only by those who are using ATOK for the first time, but also by those who have been using other Japanese input systems.
ATOK environment settings can be started by clicking [Environments] on the ATOK palette.
