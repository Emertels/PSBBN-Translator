Character input mode                           

The mode changes depending on the type of characters you enter, such as kanji/kana mixed sentences, half-width characters, symbols, etc.
There are four types of character input modes: kanji input, half-width input, code input, and symbol input, and each time you press the F10 key, you switch.
If using a mouse, click the part of the ATOK palette to switch.

Kanji input mode

Select the method for entering characters from the keyboard.
There are two input methods: Romaji/Kanji input, where you input according to the alphabet on the keyboard, and Kana/Kanji input, where you input according to the kana on the keyboard.
To set the mode to always use, start ATOK environment settings and change it on the input/conversion 1 sheet.

For Romaji/Kanji input (R-Kan)

Enter according to the alphabet on the keyboard.

[Example] Skylark
[H] [I] [B] [A] [R] [I]

There are fewer keys to memorize compared to Kana-Kanji input, but the number of key presses increases.
Start ATOK environment settings and select R-Kan in the Kanji input mode on the input/conversion 1 sheet.

Kana-Kanji input (Kana-Kan)

Enter according to the kana characters on the keyboard.

[Example] Skylark
[hi] [wa] ["] [ri]

There are more keys to memorize compared to Romaji/Kanji input, but you need to press fewer keys, so once you get used to it, you can input faster.
Start ATOK environment settings and select Kana-Kan in the Kanji input mode on the input/conversion 1 sheet.

Half-width input mode

Enter the letters, numbers, and symbols on the keyboard in half-width characters. Characters entered in half-width input mode are not converted.

Code input mode

Enter symbols and kanji from the code number.
If you don't remember the entire code number, you can search from the first few digits.
If you enter up to the number you remember and press the space key, symbols with similar code numbers will be displayed.
To switch chord systems while in chord entry mode, press Shift+F7.
Each time you press the Shift + F7 keys, the setting changes in the following order: JIS → Shift JIS → Kuten.
You can also switch by clicking in the window that appears when you enter the code.

Symbol input mode

In symbol input mode, select and enter the desired symbol from the list displayed at the bottom of the screen. Select symbols using key operations.

Key operations to select symbols
KeyOperation
→ Key/Space keyMoves cursor to character on the right
← key/Shift + Space keyMoves the cursor to the character on the left
↓ key/Conversion (next candidate) keyDisplay next 10 candidates
Up key/Shift + Conversion (next candidate) keyDisplay previous 10 candidates
Tab key Display next kupoint
Shift+Tab keyShow previous kupoint
Home keyDisplay the beginning of JIS non-kanji characters
