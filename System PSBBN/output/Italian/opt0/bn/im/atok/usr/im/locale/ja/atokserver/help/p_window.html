Setting candidate windows                           

Displays both full-width and half-width candidates in the candidate window, or displays previously converted candidates. By displaying various additional candidates, you can improve conversion efficiency.
You can also change the operating environment according to your convenience, such as how many times you press the space key to display the candidate window.

Display additional input-saving candidates in the candidate window

The function that converts previously entered characters by entering only the first character is called Save input.
The input-saving candidate is displayed at number 0 in the candidate window. If you press number 0 while a candidate is displayed at number 0 in the candidate window, it will switch to input-saving conversion candidates.

  1. Click [Preferences] on the ATOK palette.

  2. Select the input/conversion 2 sheet.

  3. Click [Candidate Window Settings].
    The Candidate Window Settings dialog box appears.

  4. Select Add in Add input-saving candidates.

  5. Click OK.
    Return to input/conversion 2 sheet.

  6. Click OK again.

*Cannot be selected when using the click palette.

Additionally display both half-width and full-width candidates in the candidate window

Both half-width and full-width candidates are additionally displayed in the candidate window.
If you turn on Number in Add half-width and full-width candidates and enter "2", "2" and "2" will be displayed in the candidate window. If it is off, only "2" will be displayed.

  1. Click [Preferences] on the ATOK palette.

  2. Select the input/conversion 2 sheet.

  3. Click [Candidate Window Settings].
    The Candidate Window Settings dialog box appears.

  4. Set to add both half-width and full-width candidates.

  5. Click OK.
    Return to input/conversion 2 sheet.

  6. Click OK again.

Display additional post-conversion candidates in the candidate window

Additional candidates that will be displayed after conversion (conversion using F6 to F11 keys) will be displayed in the candidate window.
If you turn on No half-width conversion in Add post-conversion candidates and enter "tomato", "tomato", "TOMATO", and "Tomato" will be displayed in the candidate window.

  1. Click [Preferences] on the ATOK palette.

  2. Select the input/conversion 2 sheet.

  3. Click [Candidate Window Settings].
    The Candidate Window Settings dialog box appears.

  4. Set the addition of post-conversion candidates.

  5. Click OK.
    Return to input/conversion 2 sheet.

  6. Click OK again.

Set the number of conversion operations to display the candidate window

You can set how many times you press the space key to display the suggestion window.

  1. Click [Preferences] on the ATOK palette.

  2. Select the input/conversion 2 sheet.

  3. Click [Candidate Window Settings].
    The Candidate Window Settings dialog box appears.

  4. Enter the number of times you press the space key in Number of conversions.
    If you do not want to display the suggestion window, enter 0.

  5. Click OK.
    Return to input/conversion 2 sheet.

  6. Click OK again.

Use "nu (1)" to "wa (0)" keys to select conversion candidates when inputting kana

When inputting kana, you can use the "nu" to "wa" keys to select conversion candidates.

  1. Click [Preferences] on the ATOK palette.

  2. Select the input/conversion 2 sheet.

  3. Click [Candidate Window Settings].
    The Candidate Window Settings dialog box appears.

  4. Select Select in Next candidate selection when inputting kana.
    Select Input if you want to use the "nu" to "wa" keys as numeric keys when inputting kana.

  5. Click OK.
    Return to input/conversion 2 sheet.

  6. Click OK again.
