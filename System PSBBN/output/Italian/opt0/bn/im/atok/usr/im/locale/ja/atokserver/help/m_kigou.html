Enter symbols/kanji 　　　　　　

The symbols and kanji in the JIS code table, which represents the symbols used for character input in JIS codes, can be entered using the following methods.

Input symbols using normal input/conversion operations
Convert symbols entered from the keyboard to similar symbols
Input from reading/radical conversion
Set in symbol input mode/Symbol input mode
Input using code number/Code input mode

Input symbols using normal input/conversion operations

You can convert by entering the reading and pressing the space key, Shift + space key, or convert (next candidate).
For symbols that can be converted by inputting their readings, please see Symbols that can be input using normal input/conversion operations in the appendix.

Input from pronunciation/radical conversion

You can enter the symbol or kanji reading and press the F5 key to convert.
In addition to symbols, you can also enter level 2 kanji, which is the level of kanji defined by JIS.
For more information on readings, please see the radical conversion table in the appendix.

[Example]
When inputting ﾎｱ
  1. Enter the reading "Alfa".

  2. Press F5.
    The corresponding symbol will be displayed at the bottom of the screen.

  3. Move the inverted cursor to「α」.

  4. Press Enter to confirm.
    「α」will be entered at the cursor position.

Set in symbol input mode/Symbol input mode

You can switch the character input mode (4 types of kanji and kana mixed sentences, half-width characters, codes, and symbols) to symbol input mode using ATOK, and select and input from the symbols displayed at the bottom of the screen.
When ATOK is on, the character input mode will switch each time you press the F10 key.
Also, when entering symbol input mode, you can select which code system to input from three types: Shift JIS, JIS, and Kuten.
Each time you press Shift+F7, the chord system changes.
Change the code system that is always used in the Input/Conversion 2 Sheet of ATOK Environment Settings.

  1. Press F10 several times to change to symbol input mode.
    The ATOK palette display changes to .

  2. Place the inverted cursor on the desired symbol.

  3. Press Enter to confirm.
    will be entered at the cursor position.
    Press the F10 key again several times to return to the original character input mode.

Input using code number/Code input mode

If you want to enter a symbol or kanji whose code number is known, you can use code input.
If you don't remember the entire code number, you can search from the first few digits.
If you enter up to the number you remember and press the space key, the characters with the closest code number will be displayed.
To change the chord system, press Shift+F7. Each time you press Shift+F7, the chord system changes.
Change the code system that is always used in the Input/Conversion 2 Sheet of ATOK Environment Settings.

  1. Press the F10 key several times to change to code entry mode.
    The ATOK palette display changes to .

  2. Enter the code number.

  3. Press Enter or Ctrl+M (also) to confirm.
    The text will be entered at the cursor position and you will return to Kanji input mode.
    If you want to return to the original character input mode without entering any symbols or kanji, press the F10 key again several times.
