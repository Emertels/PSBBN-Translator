Enter using face mark dictionary

Enter emoticons in the face mark dictionary, which contains emoticons created using symbols.
For emoticons that can be converted by inputting their reading, please see Emoticons that can be input by reading in the appendix.


To input emoticons by reading, you need to set the face mark dictionary to the dictionary set in Dictionary/Study Sheet in ATOK environment settings.

[example]
ReadingEmoticon
Face(*_*)
Bye bye(;_;)/~~~
Bow_(._.)_

  1. Enter the reading and press the F4 key.
    It will be converted to emoticons.

  2. Press Enter or Ctrl+M to confirm.
