Setting punctuation mark input

When multiple symbols are assigned to one keyboard, such as / or..., select which one is normally entered.
Click [Menu] in the ATOK palette and select Punctuation mode from the menu that appears to change it temporarily. You can also.

  1. Click [Preferences] on the ATOK palette.

  2. Select the input/conversion 1 sheet.

  3. In Punctuation mode, set periods, commas, symbols, and brackets.

  4. Click OK.

  3. Select the character code in Code system.

Determine the size of the blank space entered with the space key

When entering a space using the space key, you can set the size of the space (full-width or half-width) separately from the input character type.
On the screen, it is difficult to distinguish between full-width and half-width spaces. Therefore, if the size of the space is strictly important, determining the size of the blank space entered with the space key can help prevent errors and troubles.

  1. Click [Preferences] on the ATOK palette.

  2. Select the input/conversion 2 sheet.

  3. Space key blank input selects the size of the blank space entered with the space key.

  4. Click OK.

Automatically input Katakana, alphabets, numbers, and symbols in half-width characters

You can set it to convert katakana, alphabets, numbers, and symbols to half-width by simply pressing the space key.

  1. Click [Preferences] on the ATOK palette.

  2. Select the input/conversion 1 sheet.

  3. Turn on Half-width/Full-width conversion and click [Settings].
    The half-width and full-width conversion settings dialog box will be displayed.

  4. Select Half-width characters for Half-width characters.

  5. Click OK.
    Return to input/conversion 1 sheet.

  6. Click OK again.

Convert all numbers entered using the numeric keypad to half-width

Half-width numbers and symbols are always entered using the numeric keypad.
When entering half-width numbers in a sentence containing kanji and kana, it is convenient because there is no need to convert or confirm the numbers.

  1. Click [Preferences] on the ATOK palette.

  2. Select the input/conversion 2 sheet.

  3. Select ``Enter'' using the half-width numeric keypad.

  4. Click OK.
