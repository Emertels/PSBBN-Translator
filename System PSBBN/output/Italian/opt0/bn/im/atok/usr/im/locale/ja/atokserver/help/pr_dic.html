Dizionario/apprendimento                           

Configurare le impostazioni per il file dizionario utilizzato per la conversione e imparare a registrare i risultati della conversione nel dizionario.
Una combinazione di un dizionario di sistema di sola lettura, un dizionario utente di scrittura e da uno a quattro dizionari ausiliari viene impostata come un set di dizionari. E possibile impostare fino a 10 set di dizionari.
Al nome del file del dizionario verra aggiunto .dic.

■Spiegazione delle voci di impostazione

  1. Elenco dei set del dizionario
    Un elenco di file dizionario che compongono il dizionario impostato nella posizione del cursore viene visualizzato in Sommario a destra.
    Un set di dizionari e costituito da un dizionario utente per la scrittura e da una combinazione di dizionario di sistema e dizionario ausiliario per la lettura.

  2. [Set dizionario di base]
    Imposta il set di dizionari selezionato nell'elenco dei set di dizionari come set di dizionari di base.

  3. [Cambia nome set dizionario]
    Cambia il nome del set di dizionari selezionato nell'elenco dei set di dizionari. Fare clic per modificare il nome in Nome set dizionario nella finestra di dialogo Rinomina set dizionario visualizzata.

  4. Dizionario di sistema/[Riferimento]
    Imposta il dizionario principale tra i dizionari utilizzati per la conversione. E possibile fare clic su [Sfoglia] e selezionare un file dizionario dall'elenco visualizzato.

  5. Dizionario utente/[Riferimento]
    Imposta un dizionario per apprendere i risultati della conversione e scrivere le parole registrate. E possibile fare clic su [Sfoglia] e selezionare un file dizionario dall'elenco visualizzato.

  6. Dal Dizionario ausiliario 1 al Dizionario ausiliario 4/[Riferimento]
    Imposta dizionari per campi specializzati, come dizionari di terminologia medica, dizionari di terminologia legale/finanziaria, ecc. Utilizzando piu dizionari in combinazione, e possibile migliorare la precisione di conversione delle parole che non possono essere coperte dal solo dizionario di sistema. E possibile fare clic su [Sfoglia] e selezionare un file dizionario dall'elenco visualizzato.

  7. Intestazione
    Viene visualizzata l'intestazione del dizionario.

  8. Apprendimento
    Seleziona se conoscere o meno i risultati della conversione. L'apprendimento viene eseguito in unita di set di dizionari e scritto nel dizionario dell'utente. Se desideri effettuare impostazioni dettagliate per il tipo di apprendimento, fai clic su [Impostazioni avanzate].
    Fare
    Scrivi sul dizionario quello che hai imparato.
    NO
    L'apprendimento non verra eseguito.

  9. [Impostazioni avanzate]
    Configura i contenuti didattici in dettaglio, ad esempio registrando le parole apprese tramite la post-conversione nel dizionario e imparando esempi di utilizzo dell'intelligenza artificiale.

[Impostazioni avanzate]

■Spiegazione delle voci di impostazione

  1. Registrazione automatica
    In base ai risultati dell'apprendimento, imposta se registrare automaticamente o meno ogni elemento nel dizionario.
    Quando si esegue la registrazione automatica, e possibile scegliere tra tre livelli.
    Temporaneo
    Impara in memoria e non si registra nel dizionario.
    Si (debole)
    Impara le parole in memoria e registra le parole usate nuovamente nel dizionario.
    Si (forte)
    Registrati nel dizionario.

  2. Distinguere maiuscole e minuscole dai caratteri alfabetici durante la registrazione
    Quando si registrano le parole o si registrano automaticamente i risultati dell'apprendimento, se la pronuncia della parola e un carattere alfabetico, selezionare se registrarla con distinzione tra maiuscole e minuscole.

  3. Apprendimento tramite intelligenza artificiale
    In base ai risultati della conversione/conferma, scegli se registrare nel dizionario la relazione tra la frase di destinazione e le frasi che la precedono e la seguono come nuovo esempio di utilizzo dell'IA.
    NO
    L'apprendimento tramite intelligenza artificiale non verra eseguito.
    Fare (semplice)
    Nel dizionario vengono registrati solo gli esempi di utilizzo dell'IA che sono nomi composti (sostantivi, nomi propri, ecc.), riducendo cosi il numero di esempi di utilizzo da registrare. Seleziona questa opzione se non desideri aumentare la dimensione del dizionario.
    Si (dettagli)
    Registra tutti gli esempi di intelligenza artificiale nel dizionario.

  4. [Ritorna al valore iniziale]
    Riporta il contenuto della finestra di dialogo Impostazioni dettagliate di apprendimento/registrazione allo stato immediatamente successivo all'installazione.
