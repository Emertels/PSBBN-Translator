Dictionary/learning                           

Configure settings for the dictionary file used for conversion and learning to register conversion results in the dictionary.
A combination of one read-only system dictionary, one writing user dictionary, and one to four auxiliary dictionaries is set as one dictionary set. You can set up to 10 dictionary sets.
The dictionary file name will have .dic appended to it.

■Explanation of setting items

  1. Dictionary set list
    A list of dictionary files that make up the dictionary set at the cursor position is displayed under Contents on the right.
    One dictionary set consists of a user dictionary for writing and a combination of system dictionary and auxiliary dictionary for reading.

  2. [Basic dictionary set]
    Set the dictionary set selected in the dictionary set list as the basic dictionary set.

  3. [Change dictionary set name]
    Change the name of the dictionary set selected in the dictionary set list. Click to change the name in Dictionary Set Name in the Rename Dictionary Set dialog box that appears.

  4. System dictionary/[Reference]
    Set the main dictionary among the dictionaries used for conversion. You can click [Browse] and select a dictionary file from the list that appears.

  5. User dictionary/[Reference]
    Set a dictionary to learn the conversion results and write the registered words. You can click [Browse] and select a dictionary file from the list that appears.

  6. Auxiliary Dictionary 1 to Auxiliary Dictionary 4/[Reference]
    Set up dictionaries for specialized fields, such as medical terminology dictionaries, legal/financial terminology dictionaries, etc. By using multiple dictionaries in combination, you can improve the conversion accuracy of words that cannot be covered by the system dictionary alone. You can click [Browse] and select a dictionary file from the list that appears.

  7. Heading
    The dictionary heading is displayed.

  8. Learning
    Select whether or not to learn the conversion results. Learning is done in units of dictionary sets and written to the user dictionary. If you want to make detailed settings for the learning type, click [Advanced Settings].
    Do
    Write what you learned in the dictionary.
    No
    Learning will not be performed.

  9. [Advanced settings]
    Configure the learning content in detail, such as registering words learned through post-conversion in the dictionary and learning AI usage examples.

[Advanced settings]

■Explanation of setting items

  1. Automatic registration
    Based on the learning results, set whether or not to automatically register each item in the dictionary.
    When performing automatic registration, you can choose from three levels.
    Temporary
    Learns in memory and does not register in the dictionary.
    Yes (weak)
    Learn words in memory and register the words used again in the dictionary.
    Yes (strong)
    Register in the dictionary.

  2. Distinguish the case of alphabetic characters during registration
    When registering words or automatically registering learning results, if the pronunciation of the word is an alphabetic character, select whether to register it case-sensitively.

  3. AI learning
    Based on the conversion/confirmation results, choose whether to register the relationship between the target phrase and the phrases before and after it in the dictionary as a new AI usage example.
    No
    AI learning will not be performed.
    Do (simple)
    Only AI usage examples that are compound nouns (nouns, proper names, etc.) are registered in the dictionary, reducing the number of usage examples to be registered. Select this if you do not want to increase the size of the dictionary.
    Yes (details)
    Register all AI examples in the dictionary.

  4. [Return to initial value]
    Returns the contents of the Learning/Registration Detailed Settings dialog box to the state immediately after installation.
