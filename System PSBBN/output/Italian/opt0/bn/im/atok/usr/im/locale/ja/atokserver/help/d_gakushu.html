Dictionary learning                           

The function that sorts conversion candidates in order of recent use and memorizes conversion correction results is called Dictionary learning. With the dictionary learning function, the more you use the dictionary, the better the conversion efficiency will be.

Dictionary learning types and settings

There are two settings for dictionary learning: Learn, which writes the learning content to the user dictionary, and Do not learn, which does not perform learning at all.
Use the following method to set whether to learn or not.

  1. Click [Preferences] on the ATOK palette.

  2. Select Dictionary/Study Sheet.

  3. Choose whether to study or not.

  4. Click OK.

Types of automatic registration

There are seven types of learning that can be automatically registered in the dictionary:

  • Hiragana post conversion
    Use the F6 key/Ctrl+U (na) key to register the word converted to hiragana.

  • Katakana post conversion
    Use the F7 key, F8 key, Ctrl+I (ni) key, or Ctrl+O (ra) key to register the word converted to katakana.

  • Post-alphabet conversion
    Use the F8 key to F10 key, Ctrl + O (ra) key, Ctrl + P (se) key, and Ctrl + @ key to register words converted into alphabets.

  • English compound words
    When alphabets and kana are entered consecutively, they are registered as one compound word.
    [Example] ATOK user (pronunciation: ATOKuser)

  • Compound words
    Learn about converted/confirmed compound words (words connected with prefixes/suffixes, etc.) and how to separate them.
    [Example] Production/Quantity → Production quantity

  • Unregistered words
    Words that are not registered in the dictionary will be converted to katakana by re-separating the clauses. Register this katakana converted candidate in the dictionary.

  • Segment break
    Learn how to separate clauses when you re-divide them.
    [Example] Usual/roses → Usual/wild roses
