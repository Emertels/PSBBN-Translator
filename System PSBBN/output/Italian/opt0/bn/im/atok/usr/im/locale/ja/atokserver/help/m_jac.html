Automatically correct input errors                           

Automatically correct typos and convert to the correct word when you press spacebar to convert.
Since there are fewer operations to correct input errors, you can input long sentences more efficiently.
Turn on Input Support in the Input/Conversion 1 Sheet of ATOK Preferences and click [Settings] to make detailed settings for automatic input error correction.

For Romaji input

The following three patterns of input errors are automatically corrected.

excess of consonants
Automatically corrects excessive consonant input when inputting consonants consecutively to input the consonant 'tsu'.
[Example]

excess or deficiency of vowels
When vowels are continuous, such as "(consonant + vowel) + (vowel)" or "(vowel) + (vowel)," incorrect conversion caused by inputting too many or insufficient vowels is corrected. , will fix it automatically.
[Example]

Excess or deficiency of "N"
Automatically corrects erroneous conversions caused by inputting too much or not enough "N" to input "NN".
[Example]

For kana input

The following three patterns of input errors are automatically corrected.

Mistake between voiced mark and handakuten
If you mistakenly enter the half-voiced mark instead of the dakuten, it will be corrected automatically.
[Example]

Mistakes in "tsu" and "tsu"
If you enter "tsu" instead of "tsu", it will be corrected automatically.
[Example]

Mistakes between "wo" and "wa"
If you enter "wa" instead of "wo", it will be corrected automatically.
