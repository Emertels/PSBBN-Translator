Sulla linea

Non puo essere trattato come un dizionario

  • Causa:
    Il file del dizionario e danneggiato.
  • Come affrontarlo:
    E necessaria la reinstallazione.

File dizionario non impostato

  • Causa:
    Il file del dizionario non e impostato.
  • Come affrontarlo:
    Le impostazioni vengono eseguite nel Dizionario/Foglio di studio nelle impostazioni dell'ambiente ATOK.

File del dizionario non trovato

  • Causa:
    Il file dizionario non esiste con quel nome file.
  • Come affrontarlo:
    Le impostazioni vengono effettuate nel Dizionario/Foglio di studio nelle impostazioni dell'ambiente ATOK.
