Cannot be treated as a dictionary

  • Cause:
    The dictionary file is corrupted.
  • How to deal with it:
    Reinstallation required.

Dictionary file not set

  • Cause:
    The dictionary file is not set.
  • How to deal with it:
    The settings are done in Dictionary/Study Sheet in ATOK environment settings.

Dictionary file not found

  • Cause:
    The dictionary file does not exist with that file name.
  • How to deal with it:
    The settings are made in Dictionary/Study Sheet in ATOK environment settings.
