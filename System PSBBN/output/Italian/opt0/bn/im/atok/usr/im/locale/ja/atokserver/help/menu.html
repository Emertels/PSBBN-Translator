ATOK menu                           

Click [Menu] on the ATOK palette, or press Ctrl+F10 while the ATOK palette is displayed to input Displays a menu for changing conversion status, starting tools, etc.
The changes you make to each mode and input character type here are temporary, so the changes will not take effect the next time you start ATOK.
If you want to continue using the same settings, change them in the ATOK environment settings.

Character input modeChange the input mode according to the characters to be entered.
Input character typeSelect what kind of characters to input.
Kanji conversion modeSelect the method to convert the input characters into Kanji and Kana mixed sentences.
Punctuation modeChoose whether to enter characters, such as a full stop or a period, when you press the .
Kanji input modeSelect the method to input characters from the keyboard.
Colloquialism priority modeIf you want to convert spoken words preferentially, select Colloquialism priority.
Words that cannot be converted using normal settings, such as "Dekitenosa" and "Big" can be converted.
Click PaletteStarts the Click Palette where you can enter characters by moving the mouse cursor with your mouse or controller.
Environment settingsStart a tool to prepare the operating environment for comfortable input and conversion.
Register wordsRegister words in the dictionary.
HelpDisplay help for ATOK.
