Come utilizzare un dizionario                           

ATOK ti consente di combinare piu dizionari e usarli per la conversione. Questa combinazione di dizionari e denominata set di dizionari e fino a 10 set di dizionari, dal set di dizionari 1 al set di dizionari 0, possono essere scambiati e utilizzati per la conversione.

Tipi di dizionario

I dizionari possono essere suddivisi in tre tipologie:
E possibile impostare fino a quattro dizionari ausiliari, utili per inserire frasi che includono parole che non possono essere coperte dal solo dizionario di sistema.
Al nome del file del dizionario verra aggiunto .dic.

Dizionario di sistemaIl dizionario principale utilizzato per la conversione
Dizionario utenteDizionario per apprendere i risultati della conversione e scrivere la registrazione delle parole
Dizionario ausiliarioDizionari di settori specializzati come dizionari di termini legali e medici

Imposta il dizionario utilizzato per la conversione

Il set di dizionari utilizzato durante la conversione premendo il tasto spazio e chiamato set di dizionari di base.
Configurare il set di dizionari di base utilizzando il seguente metodo.

  1. Clic [Preferenze] nella palette ATOK.

  2. Seleziona Dizionario/Foglio di studio.

  3. Nell'elenco dei set di dizionari selezionare il set di dizionari da utilizzare per la conversione.

  4. Imposta il dizionario di sistema, il dizionario utente e il dizionario ausiliario.
    Fare clic su [Sfoglia] per sfogliare il file del dizionario.

  5. Fare clic su [Set dizionari di base] e selezionare un set di dizionari.

  6. Fare clic su OK.
