How to use a dictionary                           

ATOK allows you to combine multiple dictionaries and use them for conversion. This combination of dictionaries is called a dictionary set, and up to 10 dictionary sets, from dictionary set 1 to dictionary set 0, can be switched and used for conversion.

Dictionary types

Dictionaries can be divided into three types:
Up to four auxiliary dictionaries can be set, which is useful for inputting sentences that include words that cannot be covered by the system dictionary alone.
The dictionary file name will have .dic appended to it.

System dictionaryThe main dictionary used for conversion
User dictionaryDictionary for learning conversion results and writing word registration
Auxiliary dictionaryDictionaries of specialized fields such as legal and medical term dictionaries

Set the dictionary used for conversion

The dictionary set used when converting by pressing the space key is called the basic dictionary set.
Set up the basic dictionary set using the following method.

  1. Click [Preferences] on the ATOK palette.

  2. Select Dictionary/Study Sheet.

  3. In the list of dictionary sets, select the dictionary set to be used for conversion.

  4. Set the system dictionary, user dictionary, and auxiliary dictionary.
    Click [Browse] to browse the dictionary file.

  5. Click [Basic dictionary set] and select a dictionary set.

  6. Click OK.
