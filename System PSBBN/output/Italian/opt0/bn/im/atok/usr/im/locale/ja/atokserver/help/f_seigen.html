Restrizioni e dettagli                           

Spiegheremo le limitazioni e i dettagli su ATOK.

Complessivamente

  • Alcuni tasti potrebbero non essere abilitati a seconda del gestore di finestre utilizzato.

  • Le stringhe di caratteri contenenti caratteri non JIS non possono essere immesse o visualizzate correttamente.

  • Le informazioni dell'utente (dizionario ATOK, file delle impostazioni dell'ambiente, file di stile) vengono trattate come se si trovassero in una directory fissa.
