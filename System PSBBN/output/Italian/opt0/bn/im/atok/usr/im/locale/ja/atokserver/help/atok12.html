What is ATOK

ATOK is a Japanese IM developed by Just System, which combines conventional AI technology with enhanced syntactic and semantic analysis and context analysis to create a comfortable Japanese input environment.

ATOK is an acronym for Advanced Technology Of Kana-Kanji Transfer, and is pronounced "Eight-tock." Just System introduced KTIS, the first ATOK, to the computer scene in 1983, and since then we have spent a long time thinking about the ideal Japanese input. ATOK is an IM for Japanese input that Just System proudly delivers as Japan's top Japanese input system.

What is IM

In application software that requires character input, such as text editors, characters are entered using around 100 keys placed on the keyboard. The software used to make this work more efficient is called IM (Input Method), and standard rules have been established.

Software like IM is essential in the Japanese environment, which is expressed using a wide variety of character types. Only with IM will you be able to enter the various characters that make up the language you are currently using.
For example, a Japanese text contains a mixture of kanji, hiragana, katakana, and alphanumeric symbols. IM provides a way to input these character types using a limited number of key combinations.

IMs for Japanese input are available from various companies, but choosing the best IM from among them will lead to efficient Japanese input.

ATOK's Japanese processing

ATOK understands "that"

Context analysis conversion
It automatically determines the field of the input text and performs homophone processing based on context information.

Analysis of anaphoric relationships of demonstratives
Context analysis conversion has been further strengthened to appropriately judge the relationship between demonstratives in sentences (this, that, that, this, that, that, etc.) and the words they refer to, and to identify homophones. Identify correctly.

It recognizes that "that" refers to "class problem" and correctly converts it to "solved."

It recognize that "the" refers to "significant tax reduction" and correctly convert it to "policy."

It recognizes that "Ano" refers to "Himeji Castle" and correctly converts it to "Castle".

Advanced Japanese processing technology for comfortable conversion

Case frame processing
Accurately determines and converts homophone differences due to differences in sentences.

Analysis of dependency relationships
Achieves high conversion efficiency by analyzing the dependency relationships between each clause in the text.

It correctly recognizes that "window" is related to "I left it open" and "night" is related to "before daybreak."

Judgment of clause breaks
By using syntactic and semantic analysis, we can accurately determine the boundaries between clauses that are difficult to judge.

Depending on the difference between the verbs "brush" and "visit" correctly determines the break between clauses.

Number processing
When inputting sentences containing numbers, which are often used in daily life, give priority to classifiers that are easy to form when "number word + (number word) + classifier" (e.g. ○ Chapter 2, x 2nd win), and co-occurrence processing (processing to determine the connection between words) that is effective only when accompanied by number words. By enhancing it, you can convert these sentences even more correctly.
